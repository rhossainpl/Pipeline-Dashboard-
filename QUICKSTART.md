# Quick Start Guide

Get your School Launch Dashboard running in 3 steps:

## Step 1: Install Dependencies

Open a terminal in the `school-dashboard` folder and run:

```bash
npm install
```

## Step 2: Start the Server

```bash
npm start
```

You should see:
```
🚀 School Launch Dashboard Server running!
📊 Dashboard available at: http://localhost:3000
📡 API available at: http://localhost:3000/api/projects
```

## Step 3: Open in Browser

Open your web browser and go to:
```
http://localhost:3000
```

That's it! Your dashboard is now running with a backend that saves all your data automatically.

## What Happens Next?

- **First time**: The server creates a `data/projects.json` file with your default projects
- **All changes**: When you edit, add, or delete projects, they're automatically saved
- **KPIs update**: The dashboard metrics automatically update when data changes
- **Data persists**: Close and reopen the browser - your data is still there!

## Stopping the Server

Press `Ctrl+C` in the terminal to stop the server.
